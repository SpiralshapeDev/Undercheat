# UnderCheat

[Apache License, Version 2.0]: https://github.com/SpiralShapeDev/Undercheat/blob/master/LICENSE-APACHE
[Bepinex pack for Undermine]: https://www.nexusmods.com/undermine/mods/5
[KeybindLib Latest]: https://github.com/SpiralshapeDev/KeybindLib/releases

This mod exposes cheat functionality that was already built into the game. The cheat GUI in this mod contains 4 pages of cheats.

## License
UnderCheat is released under the [Apache License, Version 2.0].

### Requirements
- [Bepinex pack for Undermine]
- [KeybindLib Latest]

## Installing

1. Install [BepInEx][Bepinex pack for Undermine]
2. Download and extract this mod.
3. Copy the .dll mod file to your "<Undermine-Steam-Files>/BepInEx/plugins" directory.
4. Run the game.  Enjoy!

## Usage
Modify the entries automatically generated in your BepInEx configuration file path, usually located at [ ./BepInEx/config/SpiralMods.UnderCheat.cfg ].
If you cannot see this file, try running the game with the mod so that the file can be generated by BepInEx, if that doesn't work, verify if you have the mod correctly installed.

## Building mod
1. Clone [this GitHub repository](https://github.com/SpiralShapeDev/Undercheat.git).

2. Copy files from `<Undermine-Steam-Files>/BepInEx/core` to `.libs`
   1. `0Harmony.dll`
   2. `BepInEx.dll`
   3. `BepInEx.Harmony.dll`


3. Copy files from `<Undermine-Steam-Files>/UnderMine_Data/Managed` to `.libs`
   1. `Assembly-CSharp.dll`
   2. `BehaviorDesigner.dll`
   3. `Rewired_Core.dll`
   4. `System.dll`
   5. `Undermine.dll`
   6. `Unity.TextMeshPro.dll`
   7. `UnityEngine.dll`
   8. `UnityEngine.CoreModule.dll`
   9. `UnityEngine.TextCoreModule.dll`
   10. `UnityEngine.TextRenderingModuke.dll`
   11. `UnityEngine.UI.dll`
   12. `UnityEngine.UIModule.dll`


4. Download [KeybindLib Latest] to `.libs`
   1. `KeybindLib.dll`


5. Build solution


6. Built .dll should be located at `bin/Debug/UnderCheat.dll`
